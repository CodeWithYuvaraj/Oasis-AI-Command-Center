# Oasis AI: Gig-Worker Command Center

## AI Techniques & Algorithms Used
* *Core AI Model:* Meta Llama 3 Large Language Model (via Hugging Face API).
* *AI Technique:* Dynamic Context-Injected Prompt Engineering (combining real-time Open-Meteo weather data and city-specific traffic data to guide the LLM's logic).
* *Data Algorithms:* Geospatial coordinate mapping, JSON data parsing, and Dynamic Surge Matrix Multiplication for live earnings estimations.

## How to Run
1. Install dependencies: pip install -r requirements.txt
2. Run the dashboard: streamlit run app.py
